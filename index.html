Padeye Help

What this tool does: screens selected padeye (lifting lug) stresses by calculating bearing, shear-out, net-section tension, cheek-weld shear, and reports the governing utilisation (UC). The schematic canvas shows geometry and load direction.

Inputs

  • dp – pin diameter; dh – hole diameter.
  • rm – main-plate outer radius; rc – cheek outer radius.
  • tm – main-plate thickness; tc – cheek thickness (both sides).
  • w – fillet weld leg size for cheeks; ℓ – total length of the c–c shear paths; do not enter a per-side length.
  • fy – steel yield (N/mm²); Loading & v → Fdl.
  • α – load angle for the arrow (visual only).

Checks

  • Units: Fdl and F′ are in kN; ×1000 converts to N for stresses in MPa.
  • Bearing: fp = 1000Fdl / [dp(tm + 2tc)] ≤ 0.9fy.
  • Shear a–a: fs = 1.1 × 0.5 × 1000Fdl / Aa ≤ 0.4fy, with Aa = (rm − dh/2)tm + 2(rc − dh/2)tc.
  • Tension b–b: fa = 1000Fdl / Ab ≤ 0.45fy, with Ab = 2Aa.
  • Cheek weld: Aw = 2πrc·w/√2; F′ = tc·Fdl/(tm + 2tc); demand = 2 × 1000F′/Aw ≤ 0.4fy. The multiplier 2 is a retained model allowance on one cheek's load, not a count of welds.
  • Tear-out c–c: fs = 1000Fdl/(tm·ℓ) ≤ 0.4fy, using the total shear-path length ℓ.

How to use

  1. Enter geometry and material values (mm & N/mm²).
  2. Set design load and factor to get Fdl.
  3. Review WITHIN LIMIT / EXCEEDS LIMIT badges and Governing screening UC. These compare only the stated equations, not complete lifting-point adequacy.
  4. Use the graphic to sanity-check proportions and load direction.

Tips

  • Confirm pin/hole clearance and tolerances with the shackle manufacturer and governing project requirements.
  • Cheeks must fit the shackle jaw width.
  • Prefer generous radii/fillets to reduce stress concentrations.
  • Increase weld leg w or radius rc if weld UC governs.

For project work, establish the design basis and complete all omitted checks. The retained coefficients and factor 2 on cheek-weld load have not been traced to a governing project standard.
